This project is a basic calculator web app designed to perform standard arithmetic operations such as addition, subtraction, multiplication, and division.
It features:

✅ Responsive and user-friendly interface

💻 Built with HTML, CSS, and JavaScript

🎛️ Buttons for numbers, operators, decimal point, clear, and equal

⚡ Real-time calculation with instant display

🖥️ Can be run locally in a browser or rendered inside Google Colab using Python

This project is perfect for beginners learning web development, JavaScript DOM manipulation, or interactive UI design.
